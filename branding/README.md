# Fluid Island — branding direction

## Working identity

- **Name:** Fluid Island
- **Descriptor:** A living layer for your Linux desktop.
- **Personality:** Native, calm, responsive, practical, quietly expressive.
- **Visual idea:** A compact island-like surface that morphs to reveal current activity, then returns to a quiet state.

## Initial visual direction

- Dark neutral desktop surface.
- Rounded, compact island silhouette.
- One restrained activity indicator.
- Motion should communicate state changes rather than decorate them.
- Avoid copying Apple's exact UI, iconography, animations, or marketing assets.

`fluid-island-mark.svg` is an illustrative placeholder only. It is not the final logo, and it should be revisited after the application visual language is tested.
