# Code of Conduct

## Our commitment

Fluid Island aims to be a respectful, practical, and welcoming open-source project. Participants should be able to collaborate without harassment or personal attacks.

## Expected behavior

- Be respectful and specific in technical disagreement.
- Critique ideas and implementation, not people.
- Assume good faith while remaining open to evidence.
- Accept constructive feedback and explain decisions clearly.
- Respect privacy and do not publish another person's personal information.

## Unacceptable behavior

Harassment, discriminatory language, threats, deliberate intimidation, doxxing, and sustained personal attacks are not acceptable.

## Reporting

Report concerns privately to the project maintainers using the contact method listed in the repository profile. Do not post sensitive reports publicly. Maintainers should respond fairly and proportionately.

This code of conduct applies to project spaces and public interactions when someone is representing the project.
